# 约3分钟录屏脚本

录屏前关闭私人聊天、终端历史、账户和研究目录。只录候选仓库及相对路径；不展示桌面真实姓名、绝对路径或私有备份。

1. **0:00–0:25，定位。** 打开README首屏，说明“受监督AI研究与纸盘基础设施；今天演示合成行情和mock回答，没有实时AI或盈利证明”。
2. **0:25–0:50，运行。** 使用干净环境已安装的命令：`research-demo demo --run-dir runs/recording-01`。显示model_calls=0与network_calls=0；已存在目录换新名称，不覆盖。
3. **0:50–1:20，证据链。** 展示运行目录中的manifest、requests、imports与journal。指出输入hash、原答原字节、冻结时间、previous_sha256及请求绑定。
4. **1:20–1:55，风险语义。** 展示report中的mandatory事件、暂停点、等待期间止损退出；说明新订单暂停不等于原保护单失效。损益数值来自刻意构造的fixture，不展示“盈利战绩”。
5. **1:55–2:20，恢复。** 新终端执行 `research-demo status --run-dir runs/recording-01`，说明重启会验证数据/代码/日志链；演示记录中的operator_pause与operator_resume。
6. **2:20–2:45，测试。** 执行 `python -m unittest discover -s tests -v`，展示当前实际测试数量；指出时区、未来引用、限价约束、成本与损坏拒绝。
7. **2:45–3:00，边界。** 打开能力清单，说明尚未实现自主规划、生产沙箱、实时模型调用或实盘，不声称量化策略有效。

录屏只读展示生成的合成产物。不要把本地运行日志、虚拟环境或录屏原素材直接加入Git。
